# 최미라 — 출판 기획·편집 포트폴리오

> 책을 만들고, 구조를 설계합니다.

출판 기획·편집 경험과 AI 콘텐츠 제작 역량을 소개하는 정적 포트폴리오 웹사이트입니다. 대표 출판 작업, 연도별 출간 현황, AI·디지털 프로젝트, 전체 작업도서 아카이브를 함께 제공합니다.

- 기준일: 2026년 11월 11일
- 리뉴얼(`renewal/editorial-portfolio`)은 `main`에 병합되었습니다. 이 문서는 `main`의 구현 상태를 기준으로 작성했습니다.

## 주요 구성

### 첫 화면과 편집 관점

- 2007~2026년 연도별 출간 종수와 분야를 누적 막대그래프로 표시합니다.
- 그래프는 `books.js`를 기반으로 생성하며, 막대에 커서를 올리면 해당 연도·분야의 도서 목록을 확인할 수 있습니다.
- 분야는 어린이·청소년 / 유아 / 인문·예술·과학 / 에세이 / 실용·취미의 5개 그룹으로 집계합니다.
- Editorial Approach에서 독자의 눈높이, 정확한 내용, 함께 만드는 과정을 소개합니다.
- 주요 전문성, 작업 분야, AI 콘텐츠 기획·제작으로 확장하는 역량을 세 개의 박스로 정리했습니다.

### 01 / Selected Publishing Works — 대표 도서

대표 작업을 다섯 묶음으로 소개하며, 담당 범위와 역할을 확인할 수 있습니다.

- 용선생의 시끌벅적 과학교실: 1~22권
- 철학자가 들려주는 철학 이야기: 24종 기획
- 세계사 탐정 코난: 1~12권
- 전천당 : 행운의 갈림길: 1~3권
- 미오기傳 · 공부가 좋아서

시리즈 표지는 부채꼴 또는 세트 이미지로 전시하며, 도서 정보 버튼은 아카이브와 동일한 상세창을 엽니다.

### 02 / AI & Digital Projects — AI 확장 역량

- **TODAY’S ROCK / 오늘의 록**: 날씨·기분 기반 음악 큐레이션과 뮤지션 콘텐츠, 원고 검수·승인 과정 설계
- **YOUR FLOW / 유어 플로우**: 요가 자세 정보 분류와 탐색, 루틴 구성
- **PROMPT CRAFT / 프롬프트 크래프트**: AI 영상 콘텐츠의 기획·대본·생성 프롬프트 제작 과정 구조화
- **MOONLIGHT TAROT / 달빛 타로**: 카드 의미와 스프레드 정리, AI 타로 해석의 어조 다듬기

각 프로젝트의 화면 썸네일과 서비스 또는 GitHub 링크를 제공합니다.

### 03 / Works Archive — 작업도서 전체목록

- 현재 데이터: **148개 작업 항목, 누적 출간 219종**
- 작업 항목 수와 출간 종수는 다릅니다. 세트·시리즈는 `count`에 기록한 포함 종수로 계산합니다.
- 아카이브는 기본적으로 접혀 있으며, 펼치기 버튼이나 상단 메뉴로 열 수 있습니다.
- 검색과 출판사·분야·재직/외주 필터를 조합해 도서를 찾습니다.
- 상세창에서 작업 내용, 담당 권 목록, 코멘트, 도서 정보와 서점·출처 링크를 확인합니다.
- 표지 로딩에 실패하면 대체 텍스트 이미지를 표시합니다.

## 디자인과 PDF 저장

화면은 짙은 녹색 배경과 반투명 컬러 패널을 사용하며, 모바일 화면에 맞춰 배치를 조정합니다. PDF는 밝은 바탕의 별도 인쇄 스타일을 사용하고, 컬러 박스와 테두리의 색상 계열을 반영합니다.

1. 상단 또는 소개 영역의 **포트폴리오 PDF ↓** 버튼을 누릅니다.
2. 브라우저 인쇄 창에서 대상을 **PDF로 저장**으로 선택합니다.
3. **A4 · 가로**, 배경 그래픽 켜기, 머리글·바닥글 끄기를 확인하고 저장합니다.

버튼은 고정 PDF 파일을 내려받는 대신, 현재 페이지로 인쇄 창을 엽니다. 표지 이미지를 미리 불러오고, 아카이브를 인쇄 시 펼쳐 표시하며, 소개와 푸터의 쪽 배치를 계산합니다.

검색·필터를 적용한 상태에서는 화면에 표시된 아카이브 항목이 인쇄됩니다. 전체 목록이 필요하면 검색어와 필터를 먼저 초기화하세요. 외부 이미지·웹폰트의 로딩 상태와 브라우저 설정에 따라 출력 결과가 달라질 수 있으므로 저장 전 미리보기를 확인하세요.

## 기술과 파일 구성

HTML, CSS, JavaScript로 구현했습니다. 별도 서버, 데이터베이스, 빌드 과정이나 API 키가 필요하지 않습니다.

| 파일 / 경로 | 역할 |
| --- | --- |
| `index.html` | 페이지 구조, 대표 작업 소개, 프로젝트 링크, 소개·연락처 |
| `style.css` | 화면 디자인, 반응형 배치, 도서 상세창, PDF 인쇄 스타일 |
| `app.js` | 검색·필터, 카드·상세창, 아카이브 토글, 이미지 로딩과 인쇄 배치 |
| `books.js` | `window.BOOKS` 형식의 도서·작업 데이터 |
| `career-chart.js` | 연도·분야별 출간 종수 집계, SVG 그래프와 도서 목록 툴팁 |
| `images/renewal/` | 대표 도서 표지, 시리즈 이미지, 프로젝트 썸네일 |

도서 표지 일부는 YES24 외부 이미지 주소를 사용하며, 웹폰트도 외부 CDN에서 불러옵니다.

## 로컬 실행

1. VS Code에서 저장소 폴더를 엽니다.
2. `index.html`을 Live Server로 실행합니다.
3. 대표 도서 상세창, 아카이브 검색·필터, 그래프와 PDF 미리보기를 확인합니다.

## 배포

정적 파일을 제공하는 호스팅에 그대로 배포할 수 있습니다. 배포 대상 브랜치는 `main`입니다.

- **GitHub Pages**: 저장소 Settings → Pages → Deploy from a branch → `main` / `(root)`. 무료 플랜은 공개 저장소에서만 사용할 수 있습니다.
- **Vercel 등**: 저장소를 연결하면 빌드 설정 없이 배포됩니다.

## 내용 수정

- **대표 작업 소개·AI 프로젝트·연락처**: `index.html`
- **도서 데이터**: `books.js`
  - `id`: 상세창 연결에 쓰는 고유 번호
  - `title`, `company`, `category`, `type`: 도서명·출판사·분야·경력 유형
  - `count`: 포함 출간 종수
  - `metric`, `note`: 작업 내용·코멘트
  - `cover`, `covers`: 대표 표지·시리즈 표지 주소
  - `volumes`: 담당 권 번호·제목 목록
  - `bibliography`: 저자·출판사·출간일·ISBN·정가 등 도서 정보
  - `year` 또는 `yearCounts`: 출간연도 또는 연도별 종수
- **그래프 집계**: `career-chart.js`. `yearCounts` → `year` → 도서 정보의 출간연도 순으로 사용합니다. 연도 미확인 항목은 누적 종수에 포함하되 연도별 막대에서는 제외합니다.
- **색상·서체·간격·PDF 배치**: `style.css`

데이터의 항목 수·출간 종수는 위 기준일의 값입니다. 도서 정보를 수정하면 화면과 그래프는 다시 계산되지만, 이 문서에 적힌 수치는 별도로 갱신해야 합니다. 담당 범위, 서지정보, 판매 상태와 외부 링크는 공개·제출 전에 확인하세요.
