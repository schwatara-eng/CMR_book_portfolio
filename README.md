## 🗃️ 03 / 작업도서 전체목록

> **148개 작업 항목을 검색과 필터로 찾아본다.**

```
펼치기 → 검색·필터 → 카드 선택 → 상세창
기본은 접힘   출판사·분야·재직/외주   표지 카드   작업 내용·담당 권·도서 정보
```

- 상세창에서 작업 내용, 담당 권 목록, 코멘트, 도서 정보, 서점·출처 링크를 본다
- 표지 로딩에 실패하면 **대체 텍스트 이미지**를 보여 준다

## 🖨️ PDF로 저장하기

**1.** 상단 또는 소개 영역의 **포트폴리오 PDF ↓** 버튼을 누른다

**2.** 브라우저 인쇄 창에서 대상을 **PDF로 저장**으로 고른다

**3.** **A4 · 가로**, 배경 그래픽 켜기, 머리글·바닥글 끄기를 확인하고 저장한다

> 🔎 검색·필터를 건 상태에서는 화면에 보이는 항목만 인쇄된다. 전체 목록이 필요하면 먼저 초기화한다.
>
> ⚠️ 외부 이미지·웹폰트 로딩 상태에 따라 결과가 달라지므로 저장 전 미리보기를 확인한다.

<sub>버튼은 고정 PDF 파일을 내려받지 않고 현재 페이지의 인쇄 창을 연다. 인쇄 때는 밝은 바탕의 별도 스타일이 적용되고 아카이브가 자동으로 펼쳐진다.</sub>

## 🗂️ 파일 구성 · 실행 · 배포

```
book_portfolio/
├─ index.html         페이지 구조, 대표 작업 소개, 프로젝트 링크, 소개·연락처
├─ style.css          화면 디자인, 반응형 배치, 도서 상세창, PDF 인쇄 스타일
├─ app.js             검색·필터, 카드·상세창, 아카이브 토글, 이미지 로딩과 인쇄 배치
├─ books.js           window.BOOKS 형식의 도서·작업 데이터
├─ career-chart.js    연도·분야별 출간 종수 집계, SVG 그래프와 도서 목록 툴팁
└─ images/renewal/    대표 도서 표지, 시리즈 이미지, 프로젝트 썸네일
```

서버, 데이터베이스, 빌드 과정, API 키가 필요 없다.

**실행** — VS Code에서 폴더를 열고 `index.html`을 **Live Server**로 실행한다

**배포** — 정적 파일 호스팅에 그대로 올린다. 배포 대상 브랜치는 `main`

| 호스팅 | 방법 |
| :--- | :--- |
| GitHub Pages | Settings → Pages → Deploy from a branch → `main` / `(root)` · 무료 플랜은 공개 저장소만 |
| Vercel 등 | 저장소를 연결하면 빌드 설정 없이 배포 |

<sub>도서 표지 일부는 YES24 외부 이미지 주소를, 웹폰트는 외부 CDN을 사용한다.</sub>

## ✏️ 무엇을 어디서 고치나

| 고칠 내용 | 파일 |
| :--- | :--- |
| 대표 작업 소개 · AI 프로젝트 · 연락처 | `index.html` |
| 도서 데이터 | `books.js` |
| 그래프 집계 | `career-chart.js` |
| 색상 · 서체 · 간격 · PDF 배치 | `style.css` |

**`books.js` 항목의 필드**

| 필드 | 내용 |
| :--- | :--- |
| `id` | 상세창 연결에 쓰는 고유 번호 |
| `title`, `company`, `category`, `type` | 도서명 · 출판사 · 분야 · 경력 유형(재직/외주) |
| `count` | 포함 출간 종수 |
| `metric`, `note` | 작업 내용 · 코멘트 |
| `cover`, `covers` | 대표 표지 · 시리즈 표지 주소 |
| `volumes` | 담당 권 번호·제목 목록 |
| `bibliography` | 저자 · 출판사 · 출간일 · ISBN · 정가 등 도서 정보 |
| `year`, `yearCounts` | 출간연도 또는 연도별 종수 |

<sub>그래프는 `yearCounts` → `year` → 도서 정보의 출간연도 순으로 연도를 찾는다. 연도 미확인 항목은 누적 종수에 포함하되 연도별 막대에서는 뺀다.</sub>
