# 출판 기획·편집 포트폴리오 웹페이지

## 파일
- `index.html` : 페이지 구조
- `style.css` : 디자인 / 반응형 레이아웃
- `app.js` : 검색, 필터, 카드, 상세 팝업
- `books.js` : 전수조사 엑셀에서 변환한 96개 작업 데이터

## 실행
VS Code에서 폴더를 열고 `index.html`을 Live Server로 실행하면 됩니다.
정적 사이트라 GitHub Pages / Vercel에 그대로 배포할 수 있습니다.

## 표지 이미지
현재 `books.js`의 출처가 YES24 개별 상품 페이지로 확인된 항목은 해당 상품 ID를 이용해 표지 이미지를 표시합니다.
이미지 주소가 없거나 외부 이미지 로딩이 차단되면 자동으로 타이포그래픽 플레이스홀더가 표시됩니다.

표지를 추가하려면 `books.js`에서 해당 항목의 `cover`에 이미지 URL을 넣습니다.
예: `"cover": "https://.../cover.jpg"`

## 데이터 수정
현재 데이터는 `출판경력_도서시장성과_전수조사_1차.xlsx`의 1차 조사 결과를 기준으로 생성되었습니다.
시장 판매지수는 변동값이므로 포트폴리오 공개 전 최신 수치 재확인을 권장합니다.

## 시리즈 카드 표시
- `books.js`의 `covers` 배열에 표지 URL을 2~4개 넣으면 카드에서 2×2 시리즈 콜라주로 표시됩니다.
- `count`가 2 이상인데 표지가 1개뿐이면 한 장의 대표 표지 위에 `N종` 배지가 표시됩니다.
- 표지가 전혀 없으면 기존 플레이스홀더에 `N종` 배지가 표시됩니다.
- 표지를 추가할 때는 예: `covers: ["표지URL1", "표지URL2", ...]` 형태로 입력하면 됩니다.
